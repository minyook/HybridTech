# Android 장비 목록 검색

갱신: 2026-10-29. Android 설치형 앱의 텍스트·음성 질문에 적용합니다. 웹/PWA 파일은 보존하며 이번 수정에 포함하지 않습니다.

## 문제와 수정 범위

기존 검색은 `장비`를 일반 단어로 분류해 확인 질문을 반환했습니다. `작업장비`처럼 단어가 더 있는 질문은 기존 어휘 검색이 감독관 직무·교육·허가서 페이지를 선택하기도 했습니다. 여러 장비를 묻는 질문에는 한 페이지의 우세도보다 서로 보완하는 근거를 모으는 것이 필요합니다.

`HybridRetrieval`은 실제 현장 승인 질문·복합 질문 처리를 유지한 상태에서 **일반 장비 목록 의도**를 먼저 구분합니다. 장비·도구·장구·준비물의 일반 목록 질문이면 `EquipmentOverview`가 현재 문서의 절/항목을 용도별로 선택합니다. 질문→정답 페이지 표나 이전에 질문한 횟수는 사용하지 않습니다. 이 경로는 신경망 추론을 추가로 기다리지 않습니다.

| 질문 범위 | 선택할 용도 | 현재 가이드의 근거 쪽 |
|---|---|---|
| 작업장비·안전장비·준비물 | 측정, 조명, 환기, 호흡 보호, 추락 방지·구조, 연락 | 27, 29, 35, 36, 37 |
| 보호구·보호장구 | 호흡용 보호구와 추락 방지·구조 장구 | 36, 37 |
| 구조장비 | 구조용 장구와 구조 진입 보호장비/제한 | 37, 44 |

쪽 번호는 **현재 corpus에서 선택된 결과**이며 제품 코드의 매핑 조건이 아닙니다. 각 용도의 장비 명칭, 절 제목, 준비·사용 조건으로 실제 문단을 찾습니다. 측정·조명·환기는 교정/방폭/환기 사양 문맥을 요구하고, 보호·구조는 해당 절을 요구합니다. 단순 직무 언급·허가서 빈 양식·사고 사례를 목록의 주된 근거로 쓰지 않습니다. 근거가 없는 용도의 장비를 고정 답변으로 만들어 넣지 않습니다.

## 질문과 근거 보호

- 장비 목록과 세부 질문을 구분합니다. 가격·전압·방수 등급·점검 시기·사용 방법·고장·비교·장비가 없는 상황은 목록으로 가로채지 않고 기존 문단/의미 검색으로 넘깁니다.
- 알려진 일반 장비 질문의 명사·요청 표현·조사를 전체 문장에서 확인합니다. 잠수·방사선·용접 등 추가 분야나 알 수 없는 수식어가 있으면 밀폐공간 장비 일반 목록으로 바꾸지 않습니다. 모든 한국어 표현을 이해하는 분류기는 아닙니다.
- 같은 항목의 조건과 행동을 보존합니다. 측정기 교정, 덕트 제조사 길이와 미지정 시 제한, 폭발위험지역의 방폭형 구조, 호흡용 보호구 사용 조건, 송기라인/정전 주의, 추락위험, 구조대 대기 조건 등을 장비 이름과 함께 선택합니다.
- 목록은 제목·bullet·수치 강조가 있는 기존 Markdown 렌더링을 사용합니다. 원본 PDF·ObjectBox 본문·393개 의미 벡터는 변경하지 않습니다. 같은 쪽에서 선택한 항목은 출처를 합치고 근거 ID를 중복시키지 않습니다.
- 같은 `DocumentAnswerPlan`이 화면·음성·필요한 모델 문맥에 사용됩니다. 일반 장비 목록에는 전체 답변을 다시 생성하는 작업을 추가하지 않습니다. 과거에 저장된 오답은 자동으로 다시 쓰지 않습니다.

## 검증과 한계

**JVM 검사 59개가 통과했고 앱 APK와 계측 검사 APK 빌드가 성공했습니다.** 12개 대표 질문은 **질문 인코더 없이 제품 Kotlin 검색을 실행한 PC JVM 결과**입니다. 장비 목록 질문이 어휘 검색/모호성 확인 단계에서 잘못 처리되던 경로를 비교하며, 실기기 모델 생성·음성 인식·전 질문 정확도 점수로 해석하지 않습니다.

별도로 일반 목록 표현 19개, 보호구/구조 범위, 세부/예외/다른 분야 14개, 필수 조건, 출처 원문 일치, 쪽 번호 변경과 근거 삭제를 검사합니다. 기존 고정 183문항 회귀와 실제 질문 벡터 40개의 결정도 유지 검사합니다. 고정 집합은 개발 회귀 자료이며 새로운 모든 표현의 검색 성공을 보장하지 않습니다.

기기 설치와 실기기 응답 확인은 수행하지 않았습니다. 기존 앱 위에 업데이트하고 새 질문 `작업장비`, `보호구 종류 알려줘`, `구조 장비는 뭐가 필요해?`로 확인할 수 있습니다. 기존 대형 Gemma 모델을 다시 받을 필요는 없습니다.

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:assembleDebug :app:assembleDebugAndroidTest --offline
```

이 명령은 필요한 의존성과 검색 모델 자산이 이미 준비된 로컬 환경 기준입니다. APK 검증 수치·해시와 실제 실행 범위는 [검증 기록](validation/android-equipment-20261029.json)을 참고하세요.
