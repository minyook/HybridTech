# 가스 질문의 대상·속성별 답변 범위

갱신: 2026-11-05. Android 앱 대상. 웹/PWA·모델 설정·대화 저장 형식은 변경하지 않았다.

## 재현한 문제

‘산소도 알려줘’에 가스 전체 표, 일산화탄소 중독과 농도 표, 적정공기의 다른 가스 기준, 측정 시기까지 붙었다. 산소농도별 영향 그림도 농도 여섯 개와 설명 여섯 개가 따로 이어져 관계를 읽을 수 없었다.

원인은 다음과 같다.

- 검색은 ‘산소’를 언급하는 다른 가스의 기전 설명까지 후보로 잡았다. 그 후보의 절 전체·주변 문단을 다시 확장하면서 관련 언급이 질문의 직접 답변처럼 표시됐다.
- 이전 주제가 ‘산소와 유해가스의 종류’일 때 ‘추가로 산소도’는 `MORE`로 분류되어 이전 전체 주제로 검색했다. 명시한 하위 대상이 우선되지 않았다.
- 이전 표 수정은 격자형 표 네 개를 복원했다. 11쪽의 산소 영향 자료는 그림 아래 여섯 열에 설명이 배치된 도식이어서 그 대상에 포함되지 않았다.

## 현재 동작

`GasQuestionFocus`는 가스 이름과 요청 속성을 분리한다. 산소/O₂, 일산화탄소/CO, 이산화탄소/CO₂, 황화수소/H₂S 등은 이름/화학식으로 인식하며, 긴 이름의 일부인 ‘질소’를 별도 대상으로 세지 않는다. 이전의 가스 묶음에서 명시적으로 다른 가스나 한 가스를 요청하면 그 대상의 새 질문으로 전환한다. ‘추가로’라는 말만으로 이전 전체 목록을 되살리지 않는다.

`GasDescriptionAnswer`는 단순한 단일 가스 설명 질문에만 적용한다. 실제 문서의 해당 가스 제목 아래 본문과 검증된 표 행을 선택한다. 가스의 설명에 ‘산소’가 들어 있다는 이유만으로 산소 설명으로 취급하지 않는다. 페이지 번호나 질문별 완성 답변·농도 수치를 코드에 저장한 사전은 사용하지 않는다. 문서 제목/절·본문과 좌표로 검증된 표가 내용의 근거다.

| 질문 범위 | 선택하는 내용 |
| --- | --- |
| `산소도 알려줘` | 산소 기본 설명 → 산소 농도 기준 → 산소농도별 영향 표 → 관련 주의사항 |
| `산소 농도 기준만 알려줘` | 해당 가스의 농도 기준 항목 |
| `산소농도별 인체 영향 알려줘` | 해당 영향 표와 관련 주의사항 |
| `이산화탄소 냄새 알려줘` | 전체 가스 표의 해당 가스 행 |
| `황화수소 냄새 알려줘` | 냄새 설명과 후각 마비·냄새만으로 판단하지 말라는 조건 함께 보존 |
| `산소 유해가스 측정방법`, `산소통 관리방법`, 복수 가스 비교 | 단순 설명으로 바꾸지 않고 기존 의미 검색 경로 유지 |

이 경로는 문서에서 본문을 직접 구성하므로 질문 인코더와 Gemma를 불러 설명을 다시 생성하지 않는다. 다만 문서 인덱스 준비 비용과 화면 표시 시간은 별개다. 모든 새 질문에 같은 속도·정확도를 보장하지 않는다. 알 수 없는 속성이나 복잡한 질문은 기존 검색·일반 답변 경로에 남는다.

## 산소 영향 도식의 복원

PC 추출기가 `산소농도별 인체 영향`이라는 원문 표제와 나란한 농도 라벨을 찾고, 각 라벨 아래 설명을 같은 x 좌표의 열에서 읽는다. 일렬로 풀린 텍스트에서 농도와 설명을 임의로 짝짓지 않는다. PDF 11쪽 전체를 렌더링해 18·16·12·10·8·6%의 연결을 대조했다. 원문에 있는 환기 조건·시간·증상을 보존하고 열 줄바꿈으로 깨진 단어의 공백만 정리했다.

이 자료를 포함해 현재 검증된 구조 자료는 **11–14쪽의 다섯 표/도식**, 데이터 30행, 머리글 포함 143셀이다. 원문 쪽 본문과 PDF 카탈로그의 해시가 맞을 때만 복원한다. 원문 87개·의미 인덱스 393개는 그대로다. 임의 PDF의 모든 도식·병합 표를 해석하는 기능은 아니다.

기존 대화를 지우거나 저장된 답변을 덮어쓰지 않는다. 새 APK를 설치한 후 질문을 다시 보내서 확인한다.

## 검증 범위와 다음 확인

[검증 기록](validation/android-gas-scope-20261105.json)과 [PC 제품 코드의 질문별 실제 답변](validation/android-gas-scope-answers-20261105.md)을 함께 확인한다.

- 변경 전 S24에서 동일한 12개 범위 기준 중 1개만 통과했다. 변경 후는 사용자 요청에 따라 PC에서 검사했으며 12개 모두 통과했다. **개발에 사용한 회귀 집합이며 독립적인 미지 질문 정확도 점수가 아니다.** 두 플랫폼의 시간을 직접 비교하지 않는다.
- 기존 150개·추가 24개 질문, 전체 JVM 검사, APK/계측 APK 빌드와 Lint를 실행했다. 최종 수치는 검증 JSON에 기록한다.
- APK 서명·ZIP 무결성·포함 자산·패키지와 기존 권한 구성을 검사한다. 빌드된 APK의 테스트이며 **새 APK의 설치·화면·기기 실행 성공을 의미하지 않는다.**
- 변경 후 실기기 설치 시도는 연결 해제로 성공을 확인하지 못했고, 이후 사용자가 폰 연결 없이 APK·코드 검사를 요청해 기기 재연결과 UI 실행은 진행하지 않았다. 기기용 검사는 컴파일만 확인했다.
- 다음 실기기 확인은 새 APK 설치 후 `산소도 알려줘`, `추가로 산소도 알려줘`, `산소 농도 기준만 알려줘`의 범위와 긴 셀 줄바꿈·출처 이동을 확인하는 것이다. 최초 준비·화면 표시·음성 출력 시간은 별도로 측정한다.
