# 웹 로컬 음성 대화 설계·사용법

갱신: 2026-10-27. 이번 웹 BLE 연결·측정값 공유는 철회했다. 기존 Android BLE·음성 및 감독관 QR 인증은 유지한다.

## 사용 흐름

1. HTTPS 주소의 **질문 → 음성 대화 설정 → 로컬 음성 파일 다운로드**에서 처음 한 번 준비한다. 모델 43,622,127바이트(약 43.6MB)와 ONNX 실행 파일 약 21.6MB를 저장한다. AI 답변 모델과 별도이며 기존 모델을 다시 다운로드하지 않는다.
2. **음성 대화 시작**을 한 번 누르고 마이크를 허용한다. 매 질문마다 누르거나 누르고 있을 필요가 없다. 자동 시작/자동 권한 요청은 하지 않는다.
3. 음성을 듣고 약 1.2초 침묵하면 로컬 한국어 인식 → 기존 문서 검색/답변 → 로컬 음성 읽기 → 다시 듣기를 반복한다. 인식한 문장은 기존 질문/기록 화면에 그대로 남는다. 잘못 인식하면 종료 후 텍스트로 수정해서 다시 질문한다.
4. **대화 종료**, 화면 이동·숨김·잠금·페이지 종료·마이크 끊김으로 듣기를 중단하고 마이크를 해제한다. 다시 열린 뒤 자동 재시작하지 않는다. 인식된 말이 ‘음성 대화 종료/대화 종료/대화 그만’과 정확히 일치하면 질문 대신 종료한다.
5. 읽기가 제한되거나 설치된 한국어 음성이 없으면 오류 안내 후 멈춘다. **설치된 한국어 음성으로 답변 읽기**를 끄면 음성 질문과 화면 답변만 사용할 수 있다. 원격 TTS나 브라우저 서버 음성 인식으로 자동 전환하지 않는다.

음성 인식 준비 중에는 듣기를 쉬며 준비 완료 뒤부터 말해야 한다. 한 발화 최대 20초, 인식 출력 최대 128토큰이다. 긴 발화는 중간을 잘라 보내지 않고 중단 안내한다. 전문 용어·수치 인식 오류와 주변 사람 목소리의 자동 전송 가능성이 있으므로 조용한 환경에서 문서 안내용으로 시험한다. 음성은 작업 승인/가스 판정 명령을 실행하지 않는다.

## 처리와 메모리

`getUserMedia` 단일 채널 PCM을 AudioWorklet에서 2,048샘플씩 수집한다. 실제 AudioContext 샘플레이트를 기준으로 16kHz로 리샘플링한다. 에너지/잡음 바닥값과 발화 지속 시간·침묵 시간으로 구간을 나눈다. **신경망 VAD·화자 인식·호출어 엔진은 아니다.** 현장 잡음에서의 인식 품질은 별도 실기기 평가가 필요하다.

다국어 **Xenova/whisper-tiny q8**, 고정 revision `5332fcc35e32a33b86612b9a57a89be7906102b1`, Transformers.js 3.8.1을 사용한다. 영어 전용 `.en` 모델이 아니다. WASM CPU 1스레드로 실행하며 WebGPU는 음성 인식에 사용하지 않는다. 한국어 `transcribe`로 고정한다.

음성 인식 준비 전에 답변 모델의 자동 준비를 보류하고 정상 정리를 확인한다. 같은 `fieldguard-ai-engine` Web Lock을 확보한 뒤 STT Worker를 만든다. 음성 인식 결과를 받은 뒤 STT Worker와 잠금을 해제하고 기존 질문 경로로 넘긴다. 답변 읽기가 끝나면 다시 답변 모델을 정리하고 STT를 준비한다. 둘을 의도적으로 동시에 적재하지 않지만 Worker 종료가 브라우저 전체 메모리의 즉시 회수를 보장하지 않는다. 특히 아이폰의 메모리·발열·응답시간은 실측 전이다. 매 턴 적재 비용이 있으므로 실시간 동시 통역 수준을 주장하지 않는다.

읽는 동안 마이크 트랙과 Worklet 전달을 비활성화하고 끝난 소리의 잔향 이후 다시 듣는다. 중단 시 AbortSignal과 epoch로 늦은 권한/준비/인식/답변 결과를 버린다. ASR 적재/인식 제한 시간은 각각 120초이며 실패 후 무한 재시도하지 않는다. 미완료 기록은 localStorage에 저장하며 새로고침만으로 지우지 않는다. 명시적 재시작 뒤 공유 엔진 잠금을 확보한 작업만 새 기록을 쓰고, 본인이 시작한 정상 종료만 자기 기록을 지운다. 마커는 Jetsam 원인 확정이 아닌 완료 미확인 기록이다.

## 로컬 처리·파일

첫 준비 때 공개 Hugging Face의 고정 파일을 다운로드하고 바이트 크기와 SHA-256을 검사한다. `fieldguard-voice-tiny-v1` 캐시에 저장하고 모든 파일이 준비된 뒤 설치 표식을 쓴다. 실행 중 모델은 커스텀 캐시에서만 읽고 원격 모델 로딩을 끈다. Worker의 fetch는 로컬 blob URL만 허용한다. 음성 PCM은 Worker로만 전달하며 서버/API에 보내거나 녹음 파일로 저장하지 않는다. 기존 질문 텍스트/답변 저장 정책은 유지한다.

TTS는 OS가 `localService=true`로 보고하는 한국어 음성만 선택한다. 기기에 언어 음성 파일 설치가 필요할 수 있고 브라우저 자동 재생 정책으로 실행이 거절될 수 있다. OS 음성 구현의 오프라인 동작은 실제 기기에서 추가 확인한다. 인터넷 없는 재접속에는 기존 PWA 셸 준비와 음성 파일 저장이 모두 필요하다.

## 소스 경로

| 경로 | 역할 |
|---|---|
| `web/src/features/VoicePanel.tsx` | 다운로드·대화 시작/종료·읽기 설정·상태 |
| `web/src/voice/conversation.ts` | 듣기→인식→답변→읽기 상태 흐름과 중단 |
| `web/src/voice/segmenter.ts` | 발화/침묵 구간·길이 제한·16kHz 변환 |
| `web/public/voice-capture.js` | 마이크 AudioWorklet |
| `web/src/voice/browser-audio.ts` | 마이크 수명·로컬 TTS·Markdown 읽기 |
| `web/src/voice/catalog.ts` | 고정 모델 파일·크기·해시 |
| `web/src/voice/assets.ts` | 다운로드·검증·캐시 설치 |
| `web/src/voice/recognizer.ts` | Worker·120초 제한·미완료 기록·잠금 |
| `web/src/voice/recognizer.worker.ts` | 캐시 전용 Whisper/WASM CPU |
| `web/src/ai/runtime.ts` | 음성 인식 중 답변 모델 적재 보류·정리 |
| `web/scripts/prepare-voice.mjs` | 공식 npm ONNX 실행 파일을 public에 준비 |

`web/`에서 `npm.cmd install`, `npm.cmd run dev` 또는 `npm.cmd run build`. 대용량 WASM은 PWA 기본 셸 사전 캐시에서 제외하며 사용자가 음성 준비를 선택할 때 별도 검증 저장한다. `public/voice-runtime/`는 생성 파일로 Git에서 제외한다. 운영 서버는 기존 HTTPS·WASM MIME 설정을 유지한다.

## 검증 범위

구간 분리·잡음/충격·20초 제한·44.1/48kHz 변환, 반향 입력 차단·반복 대화·취소/늦은 결과/오류 루프 방지, 원격 음성 미선택, 캐시 누락·손상·취소와 LLM/STT 적재 순서를 자동 검사한다. PC Node ONNX CPU에서 실제 고정 모델의 저장 파일 적재/추론은 확인했다. 영어 합성 시험 음성으로 실행 경로만 검사했으며 한국어 품질 점수로 사용하지 않는다.

브라우저 UI 자동 도구가 URL을 확인하지 못해 중단되었다. **브라우저 WASM 실제 인식, 마이크/VAD 현장 품질, 한국어 전문 용어 인식, iPhone 13 Pro 연속 대화·메모리·TTS, S24/태블릿과 완전 오프라인 재실행은 미검증**이다. 이 결과를 상용 음성 기능 검증 완료로 표현하지 않는다.

참고: [Transformers.js 공식 소스](https://github.com/huggingface/transformers.js/tree/3.8.1), [고정 모델](https://huggingface.co/Xenova/whisper-tiny/tree/5332fcc35e32a33b86612b9a57a89be7906102b1), [로컬 음성 구분](https://developer.mozilla.org/en-US/docs/Web/API/SpeechSynthesisVoice/localService).
