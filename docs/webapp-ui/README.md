# O₂ Field Guard 웹앱 UI 시안

> 2026-10-14: 이 디렉터리는 초기 정적 시안 보관용입니다. 실제 검색·저장·Gemma·PWA·작업 흐름은 [`web/`](../../web/README.md)에서 구현하며, 개발 화면은 해당 폴더에서 `npm run dev`로 여는 `http://localhost:5174/`입니다. 최신 구조는 [웹 현행 설계서](../webapp/TARGET_ARCHITECTURE.md)를 참고하세요.

기존 Android 앱의 화면과 기능을 웹 서비스용 반응형 흐름으로 옮긴 클릭 가능한 시안입니다. 실제 BLE 연결, 로컬 AI 추론, 데이터 저장은 연결하지 않았습니다. 표시되는 질문·수치·기록은 화면 구성용 예시입니다.

[`index.html`](./index.html)을 브라우저에서 열어 시안을 확인하세요. 근거 화면은 프로젝트에 포함된 PDF를 상대 경로로 보여줍니다.

포함한 흐름: 온보딩, 홈, 질문과 음성, 대화 기록, 근거 PDF·읽기 보기·추출 텍스트, 가스 상태(미수신·예시 수신·데모·연결 끊김), 작업 전 점검, 문서 검색, 모델 관리, 추론 설정, 내 데이터, 위젯·알림.

| 현재 앱 기능 | 시안에서 확인할 화면 |
| --- | --- |
| 문서 검색·질문·로컬 답변 | 문서 질문, 문서 보관함, 로컬 AI 모델 |
| 답변 근거와 원본 PDF | 근거 문서의 PDF 원본·읽기 편한 보기·추출 텍스트 |
| 음성 질문 | 음성 질문, 호출 대기 상태 |
| BLE 가스·시뮬레이션 | 가스 측정의 미수신·BLE 예시·데모·연결 끊김 상태 |
| 작업 전 점검 | 5개 항목 체크와 저장 피드백 |
| 로컬 기록·설정 | 대화 기록, 추론 설정, 내 데이터, 위젯과 알림 |

수치, 장치 목록, 대화와 답변은 **디자인 예시**입니다. 센서가 새 값을 보내지 않는 상태에서는 네 가스값을 `—`로 표시합니다. 웹 서비스의 실제 저장·동기화·장치 연동 방식은 이 시안에 포함되지 않았습니다.

디자인 기준은 사용자가 제공한 `toss.md`의 파란색 단일 강조색, 회색 계열, 큰 제목, 둥근 카드, 짧은 해요체 문구입니다. 토스의 금융 서비스 화면 구성이나 브랜드 마크는 사용하지 않았습니다.
